## English

- In the lobby, press **Y** to switch the hosting line. Choose **Community · LANywhere**, then create a room in the game's **Local Wireless** menu. The line appears when the public node is available.
- Press **A** on a room and search in-game. When you choose a Community room, both consoles connect to the same public node for gameplay. Switch LAN Play rooms still join through the existing gateway.
- Use **My server** for appointment alerts and lobby password sharing. Use the in-game password on the community line.

Merge the SD ZIP into the card root and restart Atmosphère. The bilingual guide is in the app and the ZIP. Protocol checks passed. Cross-network Switch play and latency still need player confirmation.

## 中文

- 在大厅按 **Y** 切换建房线路。公共节点可用时，可选「**社区 · LANywhere**」，再到游戏里用「本地无线」建房。
- 按 **A** 选房，再到游戏内搜索。选社区房时，两台主机都直连同一公共节点。Switch LAN Play 房间仍经现有网关加入。
- 需要约局提醒或在大厅分享密码，请选「**自有网络**」。社区房的密码在游戏里使用。

将 SD 包合并到卡根目录，重启 Atmosphère。应用和安装包均有中英文教程。协议测试通过，双 Switch 跨网对局和延迟仍待实测。
