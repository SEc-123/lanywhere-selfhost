First public beta of this LANywhere fork. Includes offline game names, improved room reconnection and the optional Tesla-compatible overlay.

- Extract the SD ZIP to the SD root and restart Atmosphère. The package replaces an existing ldn_mitm with the same module ID.
- Open **LANywhere Self-host** from Album. The relay is preset; use your game's **Local Wireless** menu. **RS** switches English/Chinese.
- If you already have a compatible Tesla or Ultrahand setup, open **LANywhere** in its menu to check the module and toggle interception while idle.

Host checks and the Switch cross-build passed. A public relay test recovered the same room and bidirectional UDP. Reconnection during a game, overlay use on a physical Switch and complete two-console matches are still unverified.

[Store and pack integration](https://github.com/SEc-123/lanywhere-selfhost/blob/v0.4.7/docs/distribution/INTEGRATORS.md) · Project source: the tagged archives below. The SDK sources and build recipes are provided separately; a bit-for-bit build has not been established.
