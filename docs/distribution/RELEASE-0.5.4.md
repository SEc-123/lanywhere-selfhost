Arrange a time without keeping a room open. Join several appointments, mark Ready near the start, and find a room or receive an Ultrahand alert when one opens. An appointment expires two hours after its scheduled start, including when a list refresh fails.

The unified lobby shows each room’s source and uses that network when selected. New rooms use My server. Hosts can share or hide room passwords.

Merge the SD ZIP into the SD root and restart Atmosphère. Open **LANywhere Self-host** from Album. **B** opens the room lobby. **RS** switches languages. This beta passed host tests and the Switch cross-build. Physical cross-network joining remains unverified.
