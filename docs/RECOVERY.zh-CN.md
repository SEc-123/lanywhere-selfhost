# 游戏名称与断线恢复

- 大厅优先显示本机验证过的名称或房主提供的名称；缺少时查[离线目录](../compatibility/title-catalog/README.md)。已知共用 ID 显示候选，缺少可解析 ID 时显示房主未提供游戏名。
- 「未安装」由 Switch 系统查询确认。目录没有安装信息，也不授权直接启动游戏。
- 大厅自动重试，主机恢复前台时会刷新。大厅连接与游戏房间分别显示，旧的断线提示不会盖住已恢复的大厅。
- 游戏模块在后台尝试恢复原线路和原房间。成功后清除重连提示；保留期结束、房间已关闭或身份变更时，请从游戏重新加入。切换线路由玩家选择。

中继能恢复保留期内的席位和 UDP 通道。已断开的游戏 TCP 流需要由游戏重新建立；游戏是否能继续，还取决于游戏自身的超时和房主状态。
