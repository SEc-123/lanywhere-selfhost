# LANywhere Tesla 浮层

这是游戏中的状态与控制面板。建房、加入房间、选择网络和教程仍在 LANywhere 主应用中。

把发布包内的 `switch/.overlays/lanywhere.ovl` 放到 SD 卡对应目录，使用已安装的 Tesla 或兼容菜单打开它。菜单加载器不是这个浮层文件的一部分。插件、主应用和浮层应来自同一发布包；安装系统插件后重启主机。

- **连接、房间、房间成员、匹配**：读取本机插件的当前状态，每秒刷新一次。房间成员数不是已进入实际对局的人数。
- **联机插件**：设置随后新建的本地联机会话是否使用插件。已经创建的游戏服务不会被这个开关销毁；它也不会调用退出房间。浮层读到正在连接、已入房或正在匹配时，不允许切换。
- **记录日志**：开启或关闭插件已有的诊断日志功能。
- **重新连接插件**：重新获取本机服务句柄，不会重新连接服务器、创建房间、切换网络或退出房间。

关闭或隐藏浮层会保留当前房间。浮层不读取公开房间列表、不直接连网络、不写账号或服务器配置。遇到“连接需检查”时，在主应用中查看具体错误。

中文系统显示中文；其他系统显示英文。字体使用现有 libtesla 的系统字体支持。

## 构建与验证

正常项目构建已经包含浮层。`TARGET_VERSION` 由项目发布版本传入，NACP 名称为 `LANywhere`，作者字段为 `LANywhere contributors`。中间产物为 `console/overlay/overlay.ovl`，最终目录为 `console/out/sd/switch/.overlays/lanywhere.ovl`。

从项目根目录运行宿主回归：

```sh
python3 -B console/overlay/tests/overlay_test.py
```

测试编译实际 IPC C 文件和实际 UI C++ 文件，使用隔离的 SM、服务和 Tesla 测试替身。覆盖服务不存在、协议不兼容、部分/畸形回复、开关失败回读、活动状态阻止切换、每秒刷新、关闭不退房和中文状态。

这些测试和 AArch64 构建不等于 Tesla 真机渲染或游戏验收。插件开关的检查与设置是两次已有 IPC，并非跨服务原子操作；其语义始终是“作用于随后创建的会话”。
